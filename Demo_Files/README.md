# DEMO FILES

Folder structure:
-Host_Network
-HostUI
-Jetson_Orin_Code

## Host Network

This folder has the code for the network portion of the host, this includes the discovery, handeler, and client. This ties to the Host UI script

## Host UI

This folder has the Host UI script that is used to run the host side of the project.

## Jetson Orin Code

This folder has the code for the server that runs within the Orin Nano, the data triage controller, query handeler, and vila integration.

## Model

The VILA model is to large to host on GitHub so you will need to download the jetson container and install the model manualy, you will need to follow the guide provided within this folder on how to install and configure the model to the Jetson Orin Nano
