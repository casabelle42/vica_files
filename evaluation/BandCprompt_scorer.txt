REQUIRED CLAIM COMPONENTS

For every component of every required claim, classify it as exactly one of:

SUPPORTED
The candidate answer explicitly states the component or clearly expresses the same meaning.

CONTRADICTED
The candidate answer explicitly states information that cannot be true
at the same time as the required component.

Use CONTRADICTED only when there is a direct semantic conflict.

Two descriptions are NOT contradictory merely because they describe
different aspects of an event.

If both the candidate statement and the required component could
simultaneously be true, do NOT classify the component as CONTRADICTED.

If the candidate does not establish the required component, but does
not make it impossible or false, classify the component as
NOT_MENTIONED.

Examples:

Required: "walk toward the door"
Candidate: "walk away from the table"
Classification: NOT_MENTIONED
Reason: Both statements could simultaneously be true.

Required: "walk toward the door"
Candidate: "walk away from the door"
Classification: CONTRADICTED
Reason: The directions directly conflict.

Required: "pick up the cup"
Candidate: "walk toward the table"
Classification: NOT_MENTIONED
Reason: Walking toward the table does not establish or contradict
picking up the cup.

Required: "pick up the cup"
Candidate: "leave the cup on the table"
Classification: CONTRADICTED only if the candidate clearly establishes
that the cup was not picked up during the relevant event.

NOT_MENTIONED
The candidate answer neither supports nor contradicts the component.

Evaluate entity, action, object, location, state, and other supplied components independently.

Do not infer a more specific component from a less specific statement.

Missing information is NOT_MENTIONED, not CONTRADICTED.
CONTRADICTED requires an actual semantic conflict. A different or less specific description is not CONTRADICTED if both statements could simultaneously be true. In that case, if the required component is not established, classify it as NOT_MENTIONED

Reasonable paraphrases with the same meaning are SUPPORTED.

ENTITY COREFERENCE RULE

An entity does not need to be repeated by its full description or identifier to count as mentioned.

Pronouns and other unambiguous referring expressions count as support for an entity component when the referent can be determined from the candidate answer and analyst query.

Examples:
- "the man" followed by "he" refers to the same entity when no competing male referent is introduced.
- "the woman" followed by "she" refers to the same entity when the reference is unambiguous.

Do not mark an entity as NOT_MENTIONED solely because the candidate uses a pronoun instead of repeating the entity description.

A pronoun alone does not establish an entity if its referent cannot be determined from the candidate answer and analyst query.

If a pronoun or referring expression could reasonably refer to more than one entity, do not infer the identity.
